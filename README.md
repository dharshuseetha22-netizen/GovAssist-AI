GovAssist-AI 🤖

AI-Powered Government Scheme & Scholarship Finder

GovAssist-AI is an AI-based application that helps users discover relevant government schemes, scholarships, and benefits based on their needs and interests.

The application allows users to select domains such as:

- 🎓 Education & Scholarships
- 🌾 Agriculture
- 🏥 Medical & Healthcare
- 🚀 Business & Startups
- 🏠 Housing Schemes
- 🛵 Vehicle/Bike Schemes
- 👵 Senior Citizen Schemes
- And more

Features

✅ AI-powered scheme recommendations
✅ Simple user-friendly interface
✅ Domain-based search
✅ Quick information access
✅ Built using modern AI technology

Technologies Used

- Python
- Streamlit
- Groq AI API

How to Run Locally

1. Clone the repository:

git clone <repository-link>

2. Install required packages:

pip install -r requirements.txt

3. Add your Groq API key.

4. Run the application:

streamlit run app.py

Purpose

The goal of GovAssist-AI is to make government schemes and scholarship information easier to find and understand using Artificial Intelligence.
